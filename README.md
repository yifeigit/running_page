# 我的跑步轨迹

一个自托管的跑步数据展示页：调用 **yayarun（COROS）** 数据，交互式展示每一次跑步的起点、配速、心率与每公里分段。

## 特性
- 🗺️ 起点地图（高德地图）：按配速着色、按距离定大小，点击查看详情
- 📈 每一次跑步的**每公里配速 / 心率 / 爬升**交互图表（SVG，hover 看明细）
- 📊 总览趋势：配速趋势、每周里程、累计里程
- 🔍 可搜索的跑步记录列表
- 🔄 每日自动刷新（受 yayarun 接口每日配额限制，每公里分段会逐步补齐）

## 数据说明
- 数据由 WorkBuddy 通过 yayarun MCP 拉取并自动生成。
- Coros 仅提供**起点坐标**与**每公里分段**，无逐点 GPS 轨迹，故「轨迹」以每公里分段图呈现。
- 原始接口数据位于本地 `raw/`，出于隐私考虑**不纳入本仓库**。

## 启用真实地图（可选）
本页默认使用高德地图（合规地图源）。请在 `index.html` 顶部将：

```js
const AMAP_KEY = "Please apply for your own key at the AMap Open Platform and replace this placeholder";
```

替换为你自己的高德 Web 端 JS API Key（免费申请：https://lbs.amap.com/ ）。
未配置时页面自动降级为起点经纬度分布图，核心轨迹/配速图表照常可用。

## 隐私提示
页面与地图包含跑步起点坐标。链接分享即意味着这些坐标对外可见，请谨慎分享。
如需公开分享又不想暴露精确起点，可联系移除地图坐标、仅保留统计与分段图表。

## 重新生成数据
```bash
python build_data.py   # 读取 raw/ 生成 data/runs.js
```
